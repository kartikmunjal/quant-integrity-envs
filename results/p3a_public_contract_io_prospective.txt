Submission and execution interface

The solver reads the supplied research_source and data with this uniform contract. Submit one JSON object with exactly findings and patched_source. findings is a list of at most 1000 objects, each with exactly family and line. family is one of the vocabulary IDs above. line is the 1-based physical line number in the supplied research.py/research_source and must lie in the offending statement. Family and location must both match; duplicate claims do not match a second time and unmatched claims are false positives. The generic vocabulary does not state which problems, if any, occur in an instance.

patched_source is a complete executable Python script, limited to 100000 UTF-8 bytes. It reads the research-data JSON file whose path is sys.argv[1] (the data object alone, not the outer solver-input wrapper) and prints exactly one finite JSON output object to stdout, with no prefix or trailing text. It must preserve all required functionality and satisfy this contract on different data of the same schema; fixed numeric answers are not repairs. Findings do not substitute for correct execution. No private host files or network access are available.
