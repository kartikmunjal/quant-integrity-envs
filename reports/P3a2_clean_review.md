## Findings and disposition

1. **Blocking: stale terminal-operation fallback can misclassify a later scorer bug.** At the reviewed intermediate implementation, any caught `@journal_boundary` error leaves `Attempt.terminating_error` set. `run_with_retry` consults that field for every later unknown exception. I independently reproduced a recovered HostTimeout followed by an unrelated terminal ValueError: the call ran twice and ended classified infrastructure. This violates terminating-operation classification and can spend retry budget on scientific/programming errors. A test using only `record_exception` does not cover this path. The implementer has acknowledged the finding and proposed retaining the actual final Rollout.fail error, then explicitly attaching that cause only to failed framework summaries. That direction is appropriate; final code and regression tests still require recheck.
2. **Freeze prerequisites pending.** The first source-map inspection omitted the committed exact regression plan; it now includes that plan. Shared runtime, generator, E2 financial sources, mutations, independent checker, gate/review scripts and design are inherited from the previous source map. Final freeze tooling must bind the successful source-matching stress summaries, exact regression summaries and manifests, final tests, independent review, fixed review sample, unchanged selected exponent/image/generator, amendment, and committed implementation. A source map alone does not establish completed prerequisites. The implementation owner explicitly identified this tooling as still in progress.
3. **Prior gate invariant restored during review.** The initial round-two runner omitted the prior `oracle_four_stages` requirement. The current runner again requires solver/primary/replay/poison container IDs for every complete oracle row. The complete-row count and unique resource IDs are separately required.
4. **Storage accounting improved during review.** Initially Archive counted only its compressed row payloads and prior bytes, omitting growing current exception journals and plan bytes. It now reads actual local tree size, checks it before archive writes, and reserves space before launches. The 32 MiB round-two tracked allowance and 512 KiB shard bound remain explicit. Final inventory and manifest checks are still required. Historical artifacts are outside the new allowance and remain untouched.
