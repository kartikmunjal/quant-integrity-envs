## Resolved finding

**Initial solver failure is discarded.** In `envs/e1_pit_backtest/v1_taskset.py`, `E1Harness.launch` ignores the `ProgramResult` returned by `runtime.run` and unconditionally returns a successful empty result (lines 105–111 in the reviewed tree). An ordinary nonzero exit does not set `E1Runtime.flagged`. Finalization records command metadata but no solver success condition; `integrity` only tests source presence and the solver flag before reexecuting. Consequently the declared hard-zero condition for runtime failure is not enforced on the initial solver execution. If independent reexecution succeeds, that failed initial execution does not prevent positive reward. The comment that solver failures receive zero and the corresponding prospective design statement overstate implemented behavior. Retain initial execution status and enforce its failure before scoring, with an ordinary regression test. No example program or probe was developed or executed for this finding.

**Resolution on source reinspection, before the gate:** `E1Harness.launch` now retains `solved` and sets `runtime.flagged=True` for a nonzero exit. Finalization carries that flag into the existing hard-zero path. Added `test_initial_solver_failure_is_retained_and_zeroed` checks flag retention, recorded exit status and zero reward on a design seed. This resolves the identified source-level defect; the reviewer did not execute the test.
